# カウンターアプリを作成する

## 目的

ループエンジニアリングを試したい

## 進め方

- タスク分解してタスクごとにGitのブランチを作成する
- 作業が完了したらGitHubにプッシュしてPRを作成
- PRのレビューをユーザーが行う。レビューを見て再度、作業を行う。完了したらプッシュする
- まずはレビューをユーザーが行うが、のちにCodexが担当する想定

上記進め方は、ユーザーが作業を進める中で、改良していく前提

## 技術スタック

- HTML
- CSS
- JavaScript

フレームワークは使わない

## アプリの機能

### 初版

- +ボタン（カウントの増加） / -ボタン（減少） / リセット / 保存
- 初期表示は0とする
- カウントの範囲は 0〜999
  - 負数は許可しない（0のとき-ボタンを押しても0のまま）
  - 上限は999（999のとき+ボタンを押しても999のまま）
- 数字は最大3桁まで表示する
- 複数カウンターの管理は不要 (初版は単一カウンターの想定)
- 画面をリロードした際に、前回のカウント数から再開出来る（localStorageを利用）

## テスト / CI

- Jestでテストする
- PRをした際にテストが走る
